# Changelog

## 1.0.0 — 2026-08-10

Production-hardening release. Adds enterprise-scoped ResourcePlan overlays,
plugin marketplace metadata/lifecycle controls, configuration inventory hashes,
semantic schema versioning/migration, full object-level provenance fields,
execution history/performance statistics, memory-aware benchmarks, Docker
Compose and GitHub Actions. Existing v0.8 APIs and UOM fields remain supported.

## 0.8.0

Introduced deterministic Semantic Objects, evidence-first object APIs and model
routing on the rule-first Relay pipeline.
