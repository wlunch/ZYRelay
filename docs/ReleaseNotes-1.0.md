# Release Notes — 1.0.0

- Stabilized deterministic Semantic Object schema with additive migration.
- Added enterprise resource scope, health/compatibility metadata and YAML
  overlays for dev/test/prod.
- Added plugin manifest governance, lifecycle health and enable/disable APIs.
- Added configuration inventory hashes, execution history, retries, structured
  step logging and UOM performance metadata.
- Added benchmark peak-memory reporting, Docker Compose deployment and CI.

No breaking REST, Python SDK, CLI, UOM, semantic-index, GroundChoose or
Provenance changes were introduced.
